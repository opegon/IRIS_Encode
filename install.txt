IRIS ENCODE - installation

  1. Double-click launch.bat.

That's it.

If it finds no Python 3.11+, it installs its own: uv, a CPython and a .venv
environment, in this folder. Two to three minutes and about 140 MB the first
time, no administrator rights, nothing written anywhere else.

ffmpeg, mkvmerge and dovi_tool arrive the same way, in bin/, the first time
they are needed.

To rebuild the environment, if something went wrong:
  powershell -ExecutionPolicy Bypass -File bootstrap.ps1 -Force

If Windows reports "os error 4551": Smart App Control (on by default on a fresh
Windows 11 install) refuses a binary without an established reputation.
Install Python 3.12 from python.org - signed binaries - and run launch.bat
again, it will pick it. Details: README.md, chapter 1.4.

Installing Python yourself remains possible and is not needed:
  https://www.python.org/downloads/   (check "Add Python to PATH")
  pip install -r requirements.txt
