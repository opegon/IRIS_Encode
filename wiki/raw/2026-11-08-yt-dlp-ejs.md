# 2026-11-08 — yt-dlp et Deno : documentation et releases (IE-180)

## Wiki yt-dlp, page « EJS » (github.com/yt-dlp/yt-dlp/wiki/EJS), lue le 2026-11-08

- yt-dlp doit résoudre des défis JavaScript que YouTube présente ; il utilise
  pour cela un moteur JavaScript externe.
- Moteurs : **Deno** (recommandé, activé par défaut, version 2.3.0 au moins) ;
  Node (`--js-runtimes node`, 22.0.0 au moins) ; QuickJS / QuickJS-NG
  (`--js-runtimes quickjs`) ; Bun (déprécié). Un moteur absent du PATH se
  désigne par son chemin dans l'argument `--js-runtimes`.
- Les scripts de résolution (`yt-dlp-ejs`) sont **inclus dans `yt-dlp.exe`**
  sous Windows (et les autres builds PyInstaller) ; en installation pip, il
  faut le groupe `default`.
- La page ne dit pas ce qui reste téléchargeable sans moteur.
